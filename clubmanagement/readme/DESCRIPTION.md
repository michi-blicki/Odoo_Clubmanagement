# DESCRIPTION of `clubmanagement`

This addon is a suite to manage members of a club while being fully integrated into the club's financial system. The main goal is to avoid multiple locations to maintain member information, track member invoicing and to automate member management through intelligent member handling. By this module, the club shall be able to move the member handling from a central administration to the responsible of subclubs or departments.

The addon is developed to be used by larger clubs. Still small clubs might be happy to integrate into one application, too.
