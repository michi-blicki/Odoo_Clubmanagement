# INSTALL of `clubmanagement`

## Preparation

## Installation
* Fullfill Python requirements in `requirements.txt`
* Activate the addon `clubmanagement`

## Demo
If you would like to see `clubmanagement` in action, create a separate installation of Odoo Community Edition and install `clubmanagement_demo`. This addon contains the `Manchester Nebula FC` with club, subclub, departments, pools, teams as well as dynamically generated members.
